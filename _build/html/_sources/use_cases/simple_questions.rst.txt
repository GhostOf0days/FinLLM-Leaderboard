Understanding Financial Events
------------------------------
LLMs can explain event narratives while sometimes struggling with numeric accuracy.

.. figure:: /use_cases/images/gme_event_example.png

   :align: center
   :alt: GME event analysis

   Conceptual explanation (green) vs numerical error (red) in describing GameStop short squeeze:
   - Correct: Retail investor coordination, short squeeze mechanics
   - Incorrect: Peak price inaccuracy (actual: ~$95)
